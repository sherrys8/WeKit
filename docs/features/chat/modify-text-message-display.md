# 修改文本消息显示

> 长按任意消息气泡可修改其本地显示文本（含红包、转账等），重进聊天仍然生效，可随时恢复原文

## 类别

聊天

## 类型

可开关

## 描述

启用后，长按消息气泡的菜单里会出现「修改内容」。弹窗会列出这条气泡内的每一行文本（红包/转账气泡通常有金额、标题、说明等多行），只改你动过的那几行。

修改只作用于本机显示，不会通知对方或群内其他成员；退出聊天、微信重启后仍然保持，因为按「原文 → 替换文本」记录在本地，微信每次重绘气泡时会自动重新套用。随时可对同一条消息点「恢复原文」清除。

## 使用方法

在模块设置中启用，长按消息 → 修改内容 → 编辑后确定
